# Data Directory

このディレクトリには、Web画面（フロントエンド）で表示・検索するためのJSONデータが格納されています。

## ファイル構成

- `sample_projects.json`: 案件情報のデータソース。
- `sample_engineers.json`: 人材情報のデータソース。
- `skill_dictionary.json`: スキル検索用の辞書（同義語・関連語・除外キーワード定義）。

## データ更新手順

スプレッドシートの `export_json` シートに出力された最新の `json_text` をコピーし、対応するファイルの内容を全置換して保存してください。

## 注意事項

- **機密情報の除外**: 実運用データ（本名、詳細な単価、顧客名など）をこのディレクトリに保存する場合は、外部に公開されないよう十分注意してください。
- **デモ時の注意**: デモを行う際は、実在する個人名や機密情報を含まないよう、サンプルのままで実行するか、ダミーデータへの置換を推奨します。
- **フォーマット**: `JSON.stringify(data, null, 2)` の形式で保存することで、検索ロジックが正しく動作します。
